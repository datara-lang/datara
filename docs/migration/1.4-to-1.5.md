# Migration Guide: Datara 1.4.5 → 1.5.0

v1.5.0 «Conqueror» — финальная версия с правом ломать совместимость.
С тега v1.5.0 объявляется ОБЯЗАТЕЛЬНАЯ обратная совместимость (VISION §12):
дальнейшие изменения будут только аддитивными.

## Механические правки (авто-масштабируемые, `forgen migrate 1.4 1.5` покрывает 1–3)

### 1. `let` → `val` / `mut`
`let` остаётся работающим алиасом с предупреждением W-SYN-001 (grace-период),
но канонические формы теперь:

```datara
// 1.4.5                          // 1.5.0
let x = 10                        val x = 10
let mut y = 0                     mut y = 0
```

### 2. `String` → `Str` (остатки в старых .dtr)
`Str` — единственное строковое имя в 1.5.0; старые файлы с `String` дают
понятную диагностику.

### 3. `println(...)` → `out ...`
`println`/`eprintln` — deprecated (W0102), канон:

```datara
println("hello")          →   out "hello"
println("v:", x)          →   out fmt"v: {x}"
```

## Новое в 1.5.0 (не требует миграции)

- **TMM Layer 1/2/3** (`@arc`, `@weak`, авто-освобождение на последнем
  использовании): программы без аннотаций компилируются и освобождают память
  детерминированно; циклы владения → авто-arena.
- **TSU-срез**: `x is Int` — тег-проверка динамического значения
  (NaN-box, 8 Б, нуль бокса примитивов), `if x is T { ... }` сужает тип,
  `.as_int()/.as_float() → Outcome`, `.to_int()/.to_float()` fail-loud,
  `List<any>` гетерогенные списки; утечка val в статический контекст —
  E-ANY-001.
- **NatVar** (срез 1): `fiber_spawn/yield/sleep_ms/join/run_until_done`,
  каналы `fiber_chan_*` — стековые фиберы без раскраски.
- **stdlib.web.ssr**: XSS-safe SSR-хелперы (`html_escape` по умолчанию,
  `render_raw` — явный выбор).
- **forgen inspect --memory**: Layer 1-план освобождений.
- **forgen profile / --pgo-use**: runtime-профилирование и PGO-сборка.
- **dpm**: publish→add→install→run e2e (merkle-верификация), `dpm verify`
  ловит tamper байт-в-байт.

## Диагностика, о которых стоит знать

- **E-ANY-001**: динамическое значение в статическом параметре — сузьте
  через `is` или конвертируйте (`.as_int() or 0`).
- **E-LINK-001**: дубликат link-символа (переименуйте объявление).
- **E-TMM-001/002**: цикл владения / borrowed-утечка через FFI.

## Поведенческие изменения

- Повторное присваивание module-global в одной функции больше не даёт
  ложный E-BORROW-002 (фикс 2026-10-25).
- Строковые/числовые глобалы с именами рантайм-функций (`log`, `exp`) больше
  не падают кодогеном (datara_g_-префикс в неймспейсе data).
- builtin-вызовы (`fiber_*`, text-функции) больше не удаляются DCE как
  «pure» — side-effect-функции защищены префикс-гвардией.
