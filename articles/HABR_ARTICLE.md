### Введение: Вечный компромисс системной разработки

В 2026 году ландшафт системных языков выглядит впечатляюще, но полон болезненных компромиссов:
- C++ дает предельную свободу и контроль над регистрами CPU, но расплачивается за это десятками видов Undefined Behavior, багами повреждения памяти (use-after-free, data races) и сборками по 10-20 минут из-за раздувания шаблонов.
- Rust решил проблему безопасности без сборщика мусора, но породил другую крайность: крутая кривая обучения, жесткая борьба с borrow checker, загромождение сигнатур явными временами жизни (`'a`, `'b`), сложности при создании циклических структур, графов и ECS-архитектур, а также медленная компиляция.
- Языки со сборщиком мусора (Go, C#, Java) удобны для бэкенда, но паузы GC и непредсказуемый джиттер latency исключают их применение в хардкорном gamedev (120-240 FPS), реалтайм-аудио DSP и высокочастотных системах.

Мы задались вопросом: можно ли создать язык, который:
1. Имеет безопасность памяти и детерминированный RAII без Garbage Collector.
2. Не требует писать бесконечные лайфтаймы `'a` в каждом методе.
3. Собирается за считанные миллисекунды во время разработки, но умеет генерировать предельно быстрый машинный код под AVX2/AVX-512 для продакшена.
4. Из коробки поддерживает Data-Oriented Design (DOD) и SOA-раскладку памяти.

Так появился **Datara** и его оптимизирующий компилятор **Forgen**.

### 1. Архитектура компилятора: Почему два бэкенда лучше одного

Главная беда оптимизирующих компиляторов на базе LLVM - черепашья скорость компиляции при отладке. Когда вы меняете одну строчку в кодовой базе, вы не хотите ждать 15 секунд, пока LLVM прогонит 80 проходов оптимизации.

В компиляторе `forgen` мы применили двухдвижковую архитектуру:

```
                  [ Исходный код .dtr ]
                            |
                     [ Datara Parser ]
                            |
                   [ Семантический граф ]
                            |
               [ DMIR (Datara Mid-level IR) ]
                            |
        +-------------------+-------------------+
        |                                       |
 [ Cranelift Backend ]                  [ LLVM 18 Backend ]
   - JIT & Быстрый AOT                    - Агрессивный -O3 / LTO
   - Старт за < 30 мс                      - SIMD авто-векторизация
   - Идеально для dev-цикла               - Идеально для релиза
        |                                       |
 [ Нативный бинарник ]                  [ Продакшн бинарник ]
```

- Для разработки: команда `forgen run main.dtr` компилирует код через **Cranelift** менее чем за 30 миллисекунд. Вы правите код и сразу видите результат, как в скриптовом языке.
- Для релиза: команда `forgen build main.dtr --llvm` подключает **LLVM 18**, включая Whole-Program LTO, векторизацию циклов и специфичные инструкции процессора.

#### Автоматическая установка тулчейна (Node.js style)
Одной из частых проблем пользователей других компиляторов является ручная настройка линковщиков и LLVM. Если у пользователя нет установленного Clang/LLVM, Forgen не падает с непонятной ошибкой, а предлагает автоматическое решение:
```bash
forgen install llvm
```
Команда самостоятельно скачивает проверенную версию LLVM под вашу платформу (Windows, Linux, macOS), настраивает переменные окружения и мгновенно переходит к сборке.

### 2. Модель памяти: Аффинные типы без головоломок с лайфтаймами

В Datara отсутствует сборщик мусора, а управление ресурсами базируется на аффинной системе типов (affine ownership) и детерминированном RAII:

- Переменные по умолчанию иммутабельны (`let`), либо явно мутабельны (`mut`).
- Передача владения происходит семантикой перемещения (move by default).
- Для чтения без копирования используются представления (`view`), время жизни которых автоматически выводится компилятором локально в рамках вызывающего контекста.

Вам больше не нужно декорировать функции сложными связями времен жизни:
```datara
struct BoundingBox {
    min_x: Float
    min_y: Float
    max_x: Float
    max_y: Float
}

behavior BoundingBox {
    fn area(view this) -> Float {
        let width = this.max_x - this.min_x
        let height = this.max_y - this.min_y
        return width * height
    }
}
```

### 3. Data-Oriented Design из коробки: Аннотация `@layout(soa)`

Современные процессоры тратят до 80% циклов на ожидание данных из оперативной памяти (cache misses). Классический ООП-подход с массивами структур (Array of Structures, AoS) приводит к тому, что при обходе одной координаты процессор затягивает в L1-кэш гигантские объемы ненужных полей.

В Datara поддержка Structure of Arrays (SoA) встроена в систему типов:

```datara
@layout(soa)
struct EntityParticle {
    pos_x: Float
    pos_y: Float
    pos_z: Float
    vel_x: Float
    vel_y: Float
    vel_z: Float
    mass: Float
}
```

Компилятор автоматически раскладывает поля в памяти как непрерывные параллельные массивы float. При итерации цикл компилируется в инструкции `vaddps` / `vmulps` (AVX2/AVX-512), обрабатывая по 8 или 16 чисел за такт с нулевой стоимостью кэш-промахов.

### 4. Практический стресс-тест: 3D Raytracer против C++ и Rust

Чтобы объективно проверить качество кодогенерации, эффективность работы с памятью и планировщик потоков, мы реализовали идентичный алгоритм трассировки лучей (Raytracer) на C++, Rust, Datara, Go и Python.

Параметры теста:
- Разрешение сцены: 320 x 240 пикселей.
- Геометрия: Сцена с несколькими сферами, тенями, рассеянным и зеркальным отражением.
- Точный объем работы: Ровно **104 040** пересечений лучей со сферами.
- Гарантия честности (Checksum Parity): Контрольная сумма рендера совпадает до последнего знака после запятой: **15602392.502885**.

Конфигурация тестового стенда:
- CPU: AMD Ryzen 7 7840HS (8 ядер / 16 потоков, boost до 5.1 GHz)
- RAM: 32 GB LPDDR5X
- ОС: Windows 11 Pro 64-bit / Ubuntu 24.04 LTS

Результаты измерений:

| Язык и конфигурация | Время рендера | Контрольная сумма | Память |
|:-------------------|:--------------|:------------------|:-------|
| Datara v1.3.1 (SIMD + Chase-Lev Parallel) | 1.8 мс - 5.0 мс | 15602392.502885 | 1.4 MB |
| Rust 1.85 (opt-level=3, Rayon parallel) | 6.0 мс | 15602392.502885 | 3.2 MB |
| C++ Clang 18 (-O3 -march=native -fopenmp) | 6.0 мс | 15602392.502885 | 2.8 MB |
| Datara v1.3.1 (Single-Threaded Baseline) | 14.0 мс | 15602392.502885 | 1.2 MB |
| Go 1.22 (горутины, GOMAXPROCS=16) | 34.0 мс | 15602392.502885 | 18.5 MB |
| Python 3.12 (CPython референс) | 2960.0 мс | 15602392.502885 | 34.0 MB |

За счет комбинации параллельного планировщика Chase-Lev Work-Stealing, векторной раскладки регистров и отсутствия накладных расходов рантайма, Datara показал ускорение до 2.8x по пропускной способности по сравнению с традиционными лидерами системного программирования.

### 5. Бесшовный FFI: Подключаем C и Python без рутины

Отказ от существующей экосистемы - главная причина смерти новых языков. В Datara сделан упор на прямой FFI:

Прямой парсинг C-заголовков:
```datara
import c "sqlite3.h" with link("sqlite3.lib");

fn main() {
    mut db: RawPtr = 0 as RawPtr
    unsafe(justification: "Прямой вызов SQLite API") {
        let rc = sqlite3_open("test.db", db)
        if rc == 0 {
            println("База данных открыта успешно!")
            sqlite3_close(db)
        }
    }
}
```

Работа с Python и NumPy без копирования памяти:
```datara
use python.numpy as np

fn main() {
    let py = Py { version: "3.x" }
    py.exec(r#"
import numpy as np
matrix = np.eye(4)
trace = float(np.trace(matrix))
"#)
    let res = py.eval_float("trace")
    println(fmt"След матрицы из NumPy: {res.value}")
}
```

### Как попробовать Datara

Проект полностью открыт под лицензиями Apache-2.0 и MIT.

1. Установка на Windows:
Скачайте графический инсталлятор `Datara-Setup.exe` из релизов:
https://github.com/datara-lang/datara/releases/tag/v1.3.1

Или выполните в PowerShell:
```powershell
irm https://raw.githubusercontent.com/datara-lang/datara/main/scripts/install.ps1 | iex
```

2. Установка на Linux / macOS:
```bash
curl -fsSL https://raw.githubusercontent.com/datara-lang/datara/main/scripts/install.sh | bash
```

3. Запуск первого проекта:
```bash
forgen init my_project
cd my_project
forgen run
```
